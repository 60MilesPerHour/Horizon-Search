# About Horizon

Horizon is a private metasearch engine — it searches across multiple
{{link('engines', 'preferences')}} simultaneously and returns results without
storing anything about you.

## Why Horizon?

- No tracking, no profile, no logs. What you search stays with you.
- Results are aggregated across multiple sources for broader coverage.
- No ads, no personalization, no data sold to third parties.

## Set as default search engine

Horizon supports [OpenSearch], so you can add it directly to your browser's
search bar.

- [Firefox] — right-click the address bar and select "Add Horizon"
- [Microsoft Edge], Chrome, Safari — see browser documentation for adding
  custom search engines

When adding, ensure there's no existing entry named "Horizon" already saved.

## Search tips

Use `!` bangs to target a specific engine or category:

- `!wp paris` → Wikipedia
- `!map paris` → Map results
- `!images sunset` → Image search

See the {{link('search syntax', 'search-syntax')}} page for the full reference.

The {{link('stats page', 'stats')}} shows anonymous engine performance data.
